# 01 未婚篇

## 一、板块介绍

本板块主要研究未婚人群在恋爱、择偶、相亲、交友及婚前关系发展过程中涉及的心理、行为、社会现象与现实问题。
不搞男女对立，只为你们核心利益；谨防上当受骗、找饭票、捞男捞女、崩老头；教会你们找对象、处对象，还能教会你们不合适了如何分手，合适的话如何迈向下一步结婚。全文90%手写，10%ai辅助，纯绿色环保。

## 二、核心方向

### 01. 为你找对象做铺垫
（不敢找对象，自卑，焦虑的男生女生建议看看）
模块一：重塑自我，建设吸引力，破除自卑，敢于去爱
- 如何形成恋爱关系：从零开始的社交破冰
- 你个人的吸引力是什么：发掘你身上被忽视的闪光点，打造普通人的高光时刻
- 外貌、性格与价值观：认知自己的硬件与软件，停止容貌焦虑，找到自身定位
模块二：心理建设，武装你的心灵。
- 如何克服恋爱自卑：不因外貌、学历、收入、家庭条件否定自己
- 如何克服社交恐惧：不再害怕主动认识异性
- 如何面对拒绝：接受别人不喜欢自己，不把拒绝等同于自身价值不足
- 如何摆脱单身焦虑：不因为年龄、周围人的恋爱状态而仓促进入关系

### 02. 教你找另一半
模块一：拓圈与线下
- 从线上搭讪到线下见面的全流程指南。
- 现代交友的办法：盘点靠谱的脱单渠道（线上App、线下活动、熟人介绍等）
- 教你张开嘴搭讪打招呼：高情商开场白与社交破冰技巧
- 教你初次见面怎么留下好印象：约会选址、穿搭礼仪、话题引导
- 照骗与见光死防范：如何通过前期沟通和视频验证，降低线下见面的心理落差
模块二：互联网背调与极品避雷（怎么看人、怎么防骗）
- 带你看透网络人设与真实底色，保护好自己的钱包和感情。
- 朋友圈分析，头像分析，抖音作品分析：教你看出对方精心伪装的“人设”
- 互联网查人术：合法利用公开信息，核查对方背景（如裁判文书网、企业信息等）
- 原生家庭雷达：如何通过对方聊父母的方式，初步判断ta未来的婚姻模式
- 负债与征信排查：教你自然且不伤感情地试探对方是否有网贷、赌债或巨额超前消费
- 教会你识别捞男捞女、拜金男拜金女：如何区分“正常物质需求”和“只想白嫖”
- 鉴定装逼人、画饼人：识别“假富二代”、“伪精英”以及“未来规划全靠嘴”的选手
- 教你判断抠门者、白嫖者：AA制陷阱与隐形算计识别
- 如何辨别“养鱼”和“慢热”：看穿对方的“广撒网”套路，不当备胎

### 03. 教你选另一半
理性择偶，打破幻想，精准定位长期伴侣

- 择偶标准与其影响因素：家庭背景、社会文化是如何潜移默化影响你的决定的
- 如何选择长期伴侣：短期心动和长期适配的核心考量
- 理想伴侣与现实选择：如何克服“既要又要”的完美主义，让你看清现实
- 不同年龄阶段的择偶特点：20岁、30岁、40岁的心态变化
【补充】三观匹配：消费观、金钱观、家庭观，三观不合是婚姻最大的暗雷。
【补充】硬性条件软性条件：房子、车子、学历等，与情绪稳定、责任心、幽默感等，的博弈。
【补充】情绪成本与内耗评估：选择那个能滋养你、让你感到轻松的人，而不是条件很好但总是让你内耗、患得患失的人。
【补充】一票否决的底线：黄、赌、毒、家暴倾向、极端自私、严重心理疾病隐瞒，这些是绝对不可妥协的底线。
【补充】警惕沉没成本陷阱：不要因为“我都付出了这么多”或“年纪大了”，就勉强选择一个不合适的人结婚。
【补充】现代版“门当户对”：不仅仅是经济条件，更是原生家庭氛围、生活习惯、认知水平与抗风险能力的匹配。

模块二：恋爱危险信号预警
- 教你识别隐性PUA与服从性测试
- 微出轨与精神出轨的界定
- 恋爱中的反常行为预警
- 受害者有罪论
- 极端情绪波动预警：遇到小事就暴怒、摔东西、自残，或者一吵架就长期冷暴力（这是家暴，极端人格的前兆）
- 金钱观与利益的试探：认识不久就试探性借钱、诱导投资；或者在日常花销上极度双标、单方面索取。
- 对弱势群体的态度：观察ta对待服务员、外卖员的态度。
  
模块三：出轨识别与合法反制
-【补充】出轨的蛛丝马迹：大数据查人（外卖地址、打车记录、淘宝收货地址、微信步数）
-【补充】合法取证指南：捉奸在床能拍照吗？如何合法获取聊天记录、转账记录、行车记录仪信息？（防止因“非法侵入住宅”或“侵犯隐私”反被对方起诉）
-【补充】急救与心理建设：发现出轨后如何避免冲动行事，先稳住阵脚保护自身权益。
-【补充】如何应对第三者：打小三违法吗？如何通过法律手段要求返还“婚外赠与”的财产？

模块四：止损与退出机制
-【补充】如何体面且干净地分手：分手谈判技巧，避免死缠烂打和极端报复。
-【补充】恋爱期间的花销与礼物清算：分手后对方要求退还红包、礼物，法律上到底支不支持？
-【补充】分手后的心理重建：应对戒断反应，防止抑郁与自我怀疑。

## 三、知识收录标准

本板块采用以下收录原则：

1. 优先参考心理学、社会学及行为科学领域的学术研究。
2. 重要观点尽量寻找原始论文、调查报告或专业书籍作为依据。
3. 区分科学研究结论、社会调查结果和个人经验。
4. 注意研究样本、国家地区、年龄范围及调查时间。
5. 不将某一性别、年龄或文化群体的行为概括为所有人的共同特征。
6. 对存在争议的理论和观点保留不同研究结论。
7. 尊重个人隐私、人格尊严与人际边界。
