## 一、板块介绍

本板块主要研究未婚人群在恋爱、择偶、相亲、交友及婚前关系发展过程中涉及的心理、行为、社会现象与现实问题。

## 三、知识收录标准

本板块采用以下收录原则：

1. 优先参考心理学、社会学及行为科学领域的学术研究。
2. 重要观点尽量寻找原始论文、调查报告或专业书籍作为依据。
3. 区分科学研究结论、社会调查结果和个人经验。
4. 注意研究样本、国家地区、年龄范围及调查时间。
5. 不将某一性别、年龄或文化群体的行为概括为所有人的共同特征。
6. 对存在争议的理论和观点保留不同研究结论。
7. 尊重个人隐私、人格尊严与人际边界。
