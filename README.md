## 📖 一、项目简介

China Relationship Knowledge（中国婚恋关系知识库）是一个面向公众的开放式知识整理与数据研究项目。

项目聚焦中国当代社会中的恋爱、择偶、订婚、结婚、生育、家庭关系、婚姻危机及离婚等现实议题。

通过整理公开资料、法律法规、司法案例、学术研究、社会调查和典型情境，建立一个结构化、可检索、可持续更新的中国婚恋知识体系。

我们希望让婚恋问题不再停留于情绪化讨论，而是能够通过事实、证据、法律和社会研究进行理性分析。

## 🎯 二、项目目标

1. 建立中国婚恋关系全生命周期知识库。
2. 收集整理中国婚恋领域公开研究资料和社会调查数据。
3. 建立婚恋风险关键词体系与结构化数据集。
4. 梳理婚姻家庭相关法律法规及司法实践。
5. 研究当代中国男女婚恋观念及社会变化。
6. 为未来开发 AI 婚恋知识助手提供高质量知识数据。

## 📚 三、核心知识板块

### 01. 未婚篇：恋爱、择偶与婚前风险

- 男女恋爱与关系经营
- 择偶标准与婚恋价值观
- 异地恋、网恋、年龄差恋爱
- 恋爱经济与财产往来
- 精神出轨与关系边界
- 婚前诚信与重大事项披露
- 婚恋诈骗与虚假身份
- 婚前信息核验
- 订婚、婚约解除与财物返还
- 彩礼、嫁妆与婚房问题
- 婚前协议与财产约定
- 婚前同居与共同财产

### 02. 已婚篇：婚姻经营与婚内风险

- 婚姻忠诚与婚外情
- 第三者介入与婚外赠与
- 夫妻信任与情感边界
- 婚姻中的隐瞒与欺骗
- 亲子关系与非亲生子女争议
- 夫妻共同财产与个人财产
- 婚内债务与家庭经济
- 夫妻经济控制与家庭权力
- 婆媳关系与原生家庭干预
- 家务分工与育儿责任
- 婚姻危机与长期分居
- 高嫁、低娶及婚姻经济差异

### 03. 离婚篇：婚姻解除与权益保障

- 协议离婚与诉讼离婚
- 离婚冷静期
- 夫妻共同财产分割
- 房产分割与婚后还贷
- 夫妻共同债务
- 隐匿、转移夫妻财产
- 子女抚养权与抚养费
- 子女探望权
- 离婚损害赔偿
- 婚外情赠与财产返还
- 再婚与重组家庭

### 04. 社会现象篇：中国当代婚恋研究

- 中国青年婚恋观
- 晚婚、不婚与恐婚现象
- 婚恋市场与择偶条件
- 彩礼与婚姻经济成本
- 房产、收入与婚配关系
- 男女平等与性别角色
- 网络相亲与婚恋平台
- 社交媒体对婚恋观的影响
- 父母催婚与代际冲突
- 城乡婚恋观差异
- 婚育意愿与生育成本
- 婚姻稳定性与家庭结构变化

## 🔍 六、信息来源与可信度

项目优先采用以下信息来源：

**A级：官方权威来源**
- 国家法律法规数据库
- 中国政府网
- 国家统计局
- 最高人民法院
- 民政部及其他政府部门

**B级：学术研究来源**
- 中国知网
- 万方数据
- 高校研究机构
- 正式发表的学术论文

**C级：公开调查与专业报告**
- 正式发布的社会调查
- 高校及研究机构报告
- 有明确样本和研究方法的调查数据

**D级：公开媒体与网络讨论**
- 正规媒体报道
- 社交平台公开讨论
- 公开网络案例

D级内容仅作为社会现象观察材料，不直接作为事实或法律结论。

## 🛡️ 八、项目原则

- 尊重男女双方的平等权利。
- 不制造性别对立，不鼓励网络攻击。
- 区分事实、观点、推测和法律结论。
- 不传播未经证实的个人指控。
- 不公开个人隐私及敏感身份信息。
- 不将群体统计数据用于推断个体行为。
- 尊重原始资料的版权、许可和使用条件。
- 对涉及法律、医疗和心理健康的问题保持审慎。

本项目仅用于知识整理、社会研究与公众教育，不构成个案法律意见或专业心理诊断。
